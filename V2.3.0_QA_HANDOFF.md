## Implemented scope

- Named Functions now support explicit `uses` captures, including nested
  Functions. Named Functions and lambdas share capture semantics, diagnostics,
  lowering and native function-value behaviour.
- LSP support covers capture-aware completion, hover, definition, references,
  rename (preserving `#`/`@` sigils), semantic tokens and missing-`uses`
  quick-fixes. Workspace snapshots are bounded and on-demand; filesystem root
  URIs cannot trigger an accidental volume scan.
- Surface viewer Save now renders the current orbit/zoom/pan view with the
  active renderer and helper cache. Programmatic canonical saves remain
  deterministic.
- Plot mathematical labels support whole-string `$...$` formulas through the
  existing offline Gonum plain/LaTeX path, with bounded validation caching and
  controlled fallback for unsupported sub/superscript forms. No second TeX
  engine, network access, animation or generic 3D API was added.
- v2.3 documentation, bilingual examples and regenerated initweb documents
  were added. The runtime/public version was intentionally not bumped.
