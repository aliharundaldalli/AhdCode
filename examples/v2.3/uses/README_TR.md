# Named Function `uses` (v2.3.0)

Bu küçük örnek, modül bağlaması için `@activeLang`, kapsayan yerel değer için
`#minimum` ve iç içe named Function kullanımını gösterir. Sondaki lambda da
aynı capture temsilini kullanır; named Function ayrı bir closure modeli
getirmez.

Çalıştırmak için:

```bash
ahdcode run main.ahd
```
