# v2.6.0 release examples

[English] · [Türkçe](README_TR.md)

Small examples of the v2.6.0 network-inspection modules. Both need network
access to reach `example.com`.

- [DNS lookup](dns_lookup/README.md): `DNS.lookup`, sorted addresses, and
  refused input.
- [TLS inspection](tls_inspect/README.md): `TLS.inspect`, certificate facts,
  and an application-defined expiry policy.
