# Tabs, timers, and a ledger (v2.9)

[English] · [Türkçe](README_TR.md)

Small windows for the v2.9 GUI additions. Run each one from its own
directory with `ahdcode run main.ahd`.

## controls

Setup and Notes tabs, Small / Medium / Large, a progress bar, a date
field, and a File menu. Command+Q on macOS, Ctrl+Q on Windows and Linux,
closes the window.

## interactive

Start moves a circle and starts a background sum. Stop freezes the circle.
Cancel stops the sum and leaves the circle moving until Stop.

## gallery

A picture, a wrapping label, and a scrolling grid. Run it from this
directory so `mark.png` resolves.

## layout

A scrolling form with a menu. The v2.9 physical check of this window was
made with a mouse and keyboard.

## menu

Menu items, a shortcut, and a check item.
