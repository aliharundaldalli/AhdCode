# Disk incelemesi (v2.7.0)

[English](README.md) · [Türkçe]

Geçerli dizini barındıran dosya sisteminin kapasitesini `Disk.inspect` ile okur; toplam ve kullanılabilir gigabaytları ve kullanım yüzdesini yazdırır, programın kendi %90 uyarı eşiğini uygular ve eksik bir yolun `DiskError` fırlattığını gösterir. Her sistemde güvenle çalışır. Bkz. [Disk](../../../docs/DISK_TR.md).

```bash
ahdcode run main.ahd
```
