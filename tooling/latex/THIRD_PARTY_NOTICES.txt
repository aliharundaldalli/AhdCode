AhdCode — Third-party notices for the bundled Latex runtime
===========================================================

The AhdCode Latex standard module compiles documents with a bundled typesetting
engine and a pinned, minimal offline resource bundle. Neither is part of
AhdCode itself. This file records what is redistributed and under which terms.

Full license texts accompany this file in the `licenses/` directory.


1. Tectonic typesetting engine
------------------------------

  Component : Tectonic
  Version   : 0.17.0
  Project   : https://tectonic-typesetting.github.io/
  Source    : https://github.com/tectonic-typesetting/tectonic
  Release   : https://github.com/tectonic-typesetting/tectonic/releases/tag/tectonic%400.17.0
  License   : MIT  (licenses/TECTONIC-MIT.txt)

  AhdCode redistributes the unmodified official release executable for the
  target platform. The exact archive filename, size, and SHA-256 for every
  supported platform are pinned in `tooling/latex/assets.json`, and the
  packaging tool refuses to stage an artifact whose checksum does not match.

  Tectonic embeds XeTeX and related TeX engine code, which carries its own
  upstream permissive TeX licensing. Those terms are reproduced in the
  Tectonic distribution and its source repository.


2. TeX macro packages and formats
---------------------------------

  Provenance : TeX Live, obtained through the pinned Tectonic web bundle
               https://data1.fullyjustified.net/tlextras-2022.0r0.tar
  License    : LaTeX Project Public License, version 1.3c
               (licenses/LPPL-1.3c.txt)

  The AhdCode bundle includes only the files needed by the supported document
  baseline — the `article` class, `amsmath`/`amssymb`/`mathtools`, `graphicx`,
  `booktabs`, `array`, `geometry`, `xcolor`, `hyperref`, `fontspec`, the LaTeX
  kernel and expl3 support files, and their transitive dependencies. Every
  included file is listed by name, byte range, and SHA-256 in
  `tooling/latex/resources.json`.

  The LPPL permits redistribution of unmodified files. AhdCode does not modify
  any TeX macro file; the files are copied byte-for-byte from the pinned
  upstream bundle and verified by checksum.


3. Latin Modern fonts
---------------------

  Component : Latin Modern (OpenType), comprising the roman, sans serif, and
              monospaced families:
                lmroman10    regular, bold, italic, bolditalic
                lmsans8/9/10/12/17   regular, oblique
                lmsans10             bold, boldoblique
                lmmono8/9/10/12      regular
                lmmono10             italic
                lmmonolt10           regular, bold, oblique, boldoblique
  Author    : GUST e-foundry, derived from Computer Modern by Donald E. Knuth
  License   : GUST Font License (a LPPL-1.3c–compatible font license)
               (licenses/GUST-FONT-LICENSE.txt)

  The GUST Font License permits redistribution and use, including within
  larger works. AhdCode ships these fonts so a document compiles identically
  on a machine with no fonts installed; the generated document preamble names
  the bundled roman font files explicitly and never relies on a host system
  font.

  The sans serif and monospaced families are redistributed because fontspec
  and NFSS select them for the sans and typewriter math alphabets and text
  families, such as \mathsf and \texttt. Latin Modern is an optical-size
  family, so several design sizes of one face are required: a formula sets its
  script and scriptscript levels at smaller sizes, which select a different
  design size of the same family. The whole license above covers every listed
  face; the licensing does not differ between them.

Reproducibility
---------------

The bundle is not downloaded at run time and is not assembled ad hoc. The
packaging tool fetches exactly the pinned byte ranges listed in
`resources.json`, verifies each file's SHA-256, builds the `.ttb` with
Tectonic's own bundle builder, and then verifies the resulting bundle against
the pinned `ttb_sha256`. Independent builds produce a byte-identical bundle.

Ordinary AhdCode compilation and execution never download anything.
